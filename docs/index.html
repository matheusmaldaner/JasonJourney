01

The Ultimate Equation awaits

Jason's Journey is a roguelike game built in Pygame where you play as professor Jason Harrington, exploring the procedurally generated levels of Century Tower. Your mission: battle enemies, conquer boss fights, and solve the Ultimate Equation to unlock all knowledge in the universe.

The project was developed in 2023 as the Capstone Project for MAD2502 (Computational Mathematics) at the University of Florida, with professor Harrington's support. Level layouts are generated with PyWFC, a wave function collapse library, so every climb through the tower is different.

02

Try the level generator

The game's tower floors are laid out with wave function collapse: every tile starts as a superposition of possibilities, and the map "collapses" one lowest-entropy tile at a time while constraints propagate to its neighbors. This is an interactive demo of the technique, a simplified in-browser cousin of the PyWFC pipeline used in the game.

idle
wall corridor room floor uncollapsed

Click anywhere on the map to seed a room-floor tile at that spot; the constraint propagation carves the rest of the dungeon around your seeds. Demo of the technique only, not the game's actual tile set or ruleset.

03

What is inside the tower

Procedural levels

Tower floors are generated with wave function collapse via PyWFC, layered on top of handcrafted CSV tile maps.

Combat and bosses

Fight goblins, imps, skeletons, and zombies with an arsenal ranging from a bow to lightsabers, and take on boss fights.

Story cutscenes

Illustrated cutscenes carry the story of a professor's quest for the Ultimate Equation across the UF campus.

Pixel art and audio

Animated sprite characters, retro fonts, and sound effects for coins, arrows, and healing round out the experience.

Play locally

The game runs on Python 3.10 with Pygame. Install the dependencies, clone the repository, and start the game.

# install dependencies
pip install pywfc pygame
# clone and run
git clone https://github.com/matheusmaldaner/JasonJourney.git
cd JasonJourney
python main.py
